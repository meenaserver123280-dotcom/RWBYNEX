FAQ
Withdrawal kitne time mein hoti hai?
Withdrawal request 48 ghante ke andar process ki jaati hai. Admin manually approve karta hai.
Deposit verify kyun nahi hua?
Deposit 48 ghante mein verify hoti hai. Sahi UTR number dena zaroori hai. Wrong UTR pe deposit reject ho sakta hai.
API key kaise use karein?
Settings page pe jaao, API key copy karo. Phir /payment?key=YOUR_KEY&to=MOBILE&amt=AMOUNT endpoint use karo.
PIN bhool gaya?
Login page pe "Forgot PIN?" pe click karo. Telegram OTP se PIN reset kar sakte ho.
